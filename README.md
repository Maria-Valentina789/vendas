# vendas
Este projeto consiste no desenvolvimento de uma solução web integrada para a organização, gestão de estoques e controle de vendas de uma empresa familiar que comercializa 03 produtos principais – morango, banana e bergamota. O sistema é um e-commerce para os clientes e um painel de relatórios e gest

#--- Regras ---#
- Esse app tem como objetivo automatizar o sistema de compras de um pequeno mercado
- Todos os produtos devem ser cadastrados com: código, nome, descrição, custo, valor de venda, estoque disponível, imagem
- os registros ficam num arquivo de dados
- uma página com a apresentação do produto
- um formulário de pedido de compra (que baixa a quantidade de estoque)
- relatórios - vendas do dia, semana, mês
- exibir um gráfico comparativo das vendas dos 3 produtos
